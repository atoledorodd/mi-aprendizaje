02 · Linear + GitHub 🔗

Una tarea de Linear, de principio a fin.

🔌 Paso 0: conectar Linear con GitHub

Solo hay que hacerlo una vez.

  1. Linear → Settings → Integrations → GitHub.
  2. Connect → inicia sesión en GitHub.
  3. Da acceso al repo presu_web.
  4. En Settings → tu equipo → Workflow, comprueba que esté “PR merged → Done”.

🧪 Ejemplo con ANN-5: selector de idioma

PasoDóndeQué hago
1. RamaLinearAbro ANN-5 y pulso Cmd + Shift + . para copiar el nombre de la rama.
VS CodeClic abajo a la izquierda en main → Create new branch… → pego → Enter.
2. CambiosVS CodeCambio el código y guardo (Cmd + S).
3. CommitVS CodeSource Control → mensaje ANN-5 El selector se abre al hacer clic → Commit → Publish Branch.
4. Pull RequestGitHubCompare & pull request → en la descripción escribo Fixes ANN-5 → Create. Linear la pasa a In Progress.
5. MergeGitHubMerge pull request. Linear la pasa a Done 🎉
6. VolverVS CodeCambio a la rama main y pulso Sync para traer el cambio.
7. NotionNotionMarco “Hecho” (o le pido a Claudia que lo haga).

✨ Palabras mágicas

En la descripción del PR (o en un commit), estas palabras cierran la tarea al hacer merge:

Fixes ANN-5 · Closes ANN-5 · Resolves ANN-5

Si solo escribes ANN-5 (sin la palabra), la tarea queda enlazada pero no se cierra.
