Mi workflow: cómo uso todo junto para que funcione.

⭐ La regla de oro

Mis apps no se hablan solas. Claudia es el puente entre ellas.

Cuando algo cambia (una fecha, una tarea terminada, una idea nueva), se lo digo a Claudia y ella lo cambia en todos los sitios: Notion, Linear, Recordatorios y mi web de aprendizaje.

🔧 Antes de empezar (solo una vez)

  1. Conectar Linear con GitHub, para que las tareas se cierren solas. Cómo se hace →
  2. Subir mi-aprendizaje a GitHub en privado (opcional). Cómo se hace →
  3. En VS Code, abrir siempre la carpeta repos (File → Open Folder → repos). Ahí están mis dos repos a la vez, y así Claudia tiene todas sus notas sobre mí.

💻 Cuando trabajo en mi web

  1. Elijo una tarea en Linear, en el proyecto Web (ej. ANN-5).
  2. Creo la rama: en Linear pulso Cmd + Shift + . y en VS Code hago clic en main (abajo a la izquierda) → Create new branch… → pego.
  3. Hago los cambios. Si me atasco, le pido ayuda a Claudia: “ayúdame con ANN-5”.
  4. Commit con el código: ANN-5 El selector se abre al hacer clic → Publish Branch.
  5. Pull Request en GitHub, con Fixes ANN-5 → Merge. Linear la pasa sola a Done 🎉
  6. Vuelvo a main en VS Code y pulso Sync.
  7. Se lo digo a Claudia: “he terminado ANN-5”. Ella marca “Hecho” en Notion y actualiza mi progreso.
