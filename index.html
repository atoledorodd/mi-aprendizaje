📝 Chuleta

Empezar una tarea de Linear

En Linear abre la tarea → Cmd + Shift + . (copia el nombre de rama) → en VS Code clic abajo a la izquierda en main → Create new branch… → pegar.

Guardar cambios (commit)

Icono de ramitas (Source Control) → escribe el mensaje con el código, ej. ANN-5 Selector con clic → Commit → Sync / Publish Branch.

Cerrar la tarea sola

En GitHub: Compare & pull request → en la descripción Fixes ANN-5 → Create → Merge. Linear la pasa a Done 🎉

Volver a la versión buena

Clic abajo a la izquierda en el nombre de la rama → elige main. Después pulsa Sync para traer lo último.
