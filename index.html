📝 Chuleta

Empezar una tarea de Linear

En Linear abre la tarea → Cmd + Shift + . (copia el nombre de rama) → en VS Code clic abajo a la izquierda en main → Create new branch… → pegar.

Guardar cambios (commit)

Icono de ramitas (Source Control) → escribe el mensaje con el código, ej. ANN-5 Selector con clic → Commit → Sync / Publish Branch.

Cerrar la tarea sola

En GitHub: Compare & pull request → en la descripción Fixes ANN-5 → Create → Merge. Linear la pasa a Done 🎉

Volver a la versión buena

Clic abajo a la izquierda en el nombre de la rama → elige main. Después pulsa Sync para traer lo último.

📖 Diccionario

Repo (repositorio)
Una carpeta con memoria: guarda todos los cambios que haces.
Commit
Una “foto” de tus cambios con un mensaje que explica qué hiciste.
Rama (branch)
Un borrador para probar cosas sin tocar la versión buena (main).
Push / Sync
Subir tus commits a GitHub (y bajar los que haya allí).
Pull Request (PR)
Pedir “mezcla mi borrador con la versión buena”.
Merge
Mezclar de verdad: tus cambios entran en main.
Issue (Linear)
Una tarea, con un código como ANN-5.
Para marcar un paso como hecho: cambia false por true en progreso.js y recarga la página.
